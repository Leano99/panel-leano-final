Setelah tersambung, follow/like/gift/komentar asli dari live TikTok kamu otomatis muncul di overlay — tombol manual di tab "Alert Overlay" tetap bisa dipakai kapan saja sebagai tambahan. Ini pakai library komunitas tidak resmi, jadi bisa berhenti bekerja sewaktu-waktu kalau TikTok mengubah sistemnya. Tanpa API key, koneksi sering gagal/lambat karena dibatasi ketat — bikin API key gratis di eulerstream.com (tinggal daftar, tanpa kartu kredit), lalu tempel di kolom di atas.
